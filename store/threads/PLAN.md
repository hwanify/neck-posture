# Threads 0 → 시작 플랜 (14일)

스레드는 **사람 이야기 + 댓글**로 퍼집니다. 광고 같은 글보다 "만든 사람이 솔직하게 쓰는 글"이 잘 됩니다.
그래서 이 계정은 브랜드 계정이 아니라 **"고개가 기우는 사람이 앱을 만든 기록"**으로 운영합니다.

---

## 0. 계정 세팅 (첫날 10분)

**이름**
```
Plumb | 고개 기울기 알림
```

**소개글**
```
고개가 늘 오른쪽으로 기우는 사람이 만든 앱
에어팟이 고개 기울기를 알려줘요 · 무료
만드는 과정 솔직하게 기록 중
```

**링크**: `https://apps.apple.com/app/id6820913429`

**프로필 사진**: 앱 아이콘 (`assets/icon.png`). 얼굴 공개가 괜찮으면 본인 사진이 더 잘 됩니다.

**인스타 연동**: 인스타 프로필에 스레드 배지 표시 켜기. 릴스 올릴 때 "스레드에도 공유" 켜기.

---

## 1. 운영 원칙

1. **하루 1~2개** 올리기. 14일 동안 거르지 않는 게 제일 중요합니다.
2. **주제 태그 1개**만 붙이기 (글마다 아래에 적어 둠).
3. **링크는 본문에 넣지 않기.** 필요하면 내 글에 첫 댓글로 달기. (외부 링크 글은 노출이 줄어든다는 경험담이 많습니다.)
4. **내 글 댓글은 1시간 안에 전부 답글.** 답글이 달리는 글을 스레드가 더 퍼뜨립니다.
5. **매일 30분 남의 글에 답글 달기** (가장 중요, 아래 3번).
6. 숫자·후기는 **실제 있는 것만** 씁니다. 빈칸 `[ ]`은 실제 숫자로 채우거나 그 문장을 지웁니다.
7. 올리는 시간: 평일 **아침 8시 / 점심 12시 / 밤 10~11시** 중 하나.

## 3. 매일 30분: 남의 글에 답글 달기 (팔로워 0일 때 제일 효과 큼)

팔로워가 없을 때는 내 글보다 **남의 인기 글에 단 답글**이 더 많이 보입니다.

- 검색할 주제: `1인개발`, `앱개발`, `공부`, `직장인`, `스터디`, `자세`, `에어팟`, `아이폰`
- 좋아요 많은 글에 **진심 답글** 10~20개 (공감, 경험, 질문).
- **답글에 앱 홍보·링크 금지.** 프로필을 보고 들어오게 합니다.
- 다른 1인 개발자 글에는 꾸준히 답글 → 서로 스친이 되기 쉽습니다.

## 4. 댓글 답장 템플릿 (합니다체)

- **어디서 받아요?** → `App Store에서 'Plumb' 검색하시면 나옵니다. 프로필 링크에도 있습니다.`
- **유료예요?** → `무료입니다. 광고나 회원가입도 없습니다.`
- **갤럭시는요?** → `지금은 아이폰과 헤드 트래킹이 되는 에어팟(프로, 맥스, 3세대 이상)만 지원합니다. 원하시는 분이 많으면 검토해 보겠습니다.`
- **일반 에어팟(2세대)도 돼요?** → `아쉽게도 2세대에는 헤드 트래킹 센서가 없어서 3세대 이상이 필요합니다.`
- **음악 들으면서 돼요?** → `네, 음악과 같이 들립니다. 음악을 끊지 않습니다.`
- **효과 있어요?** → `의료 기기는 아니고, 기울어진 걸 알아채게 도와주는 앱입니다. 써보시고 느낌 알려주시면 감사하겠습니다.`

## 5. 7일차 / 14일차 점검

스레드 앱 > 프로필 > 인사이트에서 확인:

- 조회수보다 **답글 수**가 많은 글 유형이 무엇인지 → 그 유형을 다음 주에 2배로.
- 팔로워가 늘어난 날 무슨 글을 올렸는지.
- 반응 없는 유형(예: 영상만 올린 글)은 줄이기.
