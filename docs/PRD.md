# 제품 기획서 (PRD) — 바로목 (가칭)

> AirPods의 헤드 트래킹 센서로 **목의 좌우 기울어짐(측면 굴곡, lateral tilt)** 을 감지해
> 바른 자세로 돌아오도록 알려주는 iOS 앱. React Native(Expo)로 개발한다.

---

## 1. 배경 / 문제 정의

- 공부·업무·스마트폰 사용 중에 무의식적으로 고개를 한쪽으로 기울이는 습관은
  목·어깨 근육의 좌우 불균형과 통증으로 이어지기 쉽다.
- 기존 자세 교정 앱은 대부분 **카메라**(정면에 폰을 세워둬야 함)나 **별도 웨어러블**(추가 구매)이 필요하다.
- AirPods Pro/Max/3세대 이상에는 공간 음향용 **모션 센서**가 이미 들어 있고,
  iOS는 `CMHeadphoneMotionManager`로 이 데이터를 앱에 공개한다.
  → **이미 귀에 꽂고 있는 이어폰**만으로 자세를 감지할 수 있다.

## 2. 목표

| 구분 | 목표 |
| --- | --- |
| 사용자 목표 | 고개가 일정 각도 이상 기울어진 채 일정 시간 지나면 즉시 알아채고 바로잡는다 |
| 제품 목표 | 착용만 하면 별도 조작 없이 백그라운드에서 감지·알림이 동작한다 |
| 성공 지표 (MVP) | 세션 중 "바른 자세 유지 비율"이 사용 2주 후 사용 첫 주 대비 상승 / D7 리텐션 / 오탐 신고율 |

### 비목표 (MVP 범위 밖)
- Android 지원 (AirPods 헤드 모션 API가 iOS에만 존재)
- 거북목(앞으로 숙임, pitch) 감지 → v2
- 의료 기기 수준의 진단 / 치료 효과 주장

## 3. 타겟 사용자

1. **공부하는 학생 / 수험생** — 장시간 책상 앞, 음악·백색소음 들으며 공부
2. **재택·사무직 직장인** — 회의·음악용으로 AirPods 장시간 착용
3. **목·어깨 통증이 있는 사람** — 습관 교정 동기가 강함

공통 조건: iPhone + 헤드 트래킹 지원 AirPods 보유.

## 4. 지원 기기

- iOS 14 이상 (`CMHeadphoneMotionManager` 도입 버전). 실제 최소 버전은 사용할 Expo SDK 요구사항을 따른다.
- 헤드 모션 지원 이어폰: AirPods Pro(1·2세대), AirPods Max, AirPods(3세대 이상), 일부 Beats(예: Fit Pro)
  - 정확한 지원 목록은 PoC 단계에서 실기기로 확인 후 앱 내 안내 문구에 반영.
- 미지원 이어폰 연결 시: "이 이어폰은 자세 감지를 지원하지 않아요" 안내.

## 5. 핵심 사용자 시나리오

1. 앱 설치 → 온보딩(작동 원리, 모션 권한 요청) → AirPods 연결 확인
2. **캘리브레이션**: "편하게 바른 자세로 정면을 보세요" → 3초간 기준 자세 측정
3. **세션 시작** → 화면을 꺼도/다른 앱을 써도 감지 계속
4. 고개가 기준보다 **10° 이상** 기울어진 상태로 **5초 이상** 지속
   → AirPods로 짧은 알림음 + 진동 (기울어진 반대쪽 귀에서 소리 → "이쪽으로 돌아오세요")
5. 자세를 바로 하면 "좋아요" 피드백(선택)
6. 세션 종료 → 리포트: 바른 자세 비율, 경고 횟수, 좌/우 어느 쪽으로 더 기우는지
7. 통계 탭에서 일/주 단위 추이 확인

## 6. 기능 명세

### 6.1 MVP (P0)

| ID | 기능 | 설명 |
| --- | --- | --- |
| F1 | 온보딩 & 권한 | 앱 소개, 모션(Motion & Fitness) 권한 요청, 알림 권한 요청 |
| F2 | 기기 상태 표시 | 헤드 모션 지원 이어폰 연결/해제 상태 실시간 표시 |
| F3 | 캘리브레이션 | 3초간 평균 자세를 기준(0°)으로 저장. 착용 각도가 사람마다 달라 필수 |
| F4 | 실시간 모니터링 | 머리 일러스트가 실제 기울기대로 움직임 + 현재 각도(°) 표시, 좌/우 방향 표시 |
| F5 | 자세 경고 | 임계각·지속시간 초과 시 알림음(공간 방향성) / 햅틱 / 로컬 알림 |
| F6 | 세션 기록 | 세션별 시작·종료, 바른 자세 비율, 경고 횟수, 좌/우 편향, 평균 각도 |
| F7 | 설정 | 민감도(임계각 5~20°), 지속시간(3~30초), 알림 방식 on/off, 재캘리브레이션 |
| F8 | 백그라운드 감지 | 화면 꺼짐/다른 앱 사용 중에도 감지 (기술 리스크 — TECH_SPEC 참조) |

### 6.2 v1.1 (P1)
- 통계 화면: 일/주/월 차트, 시간대별 기울어짐 히트맵
- 스트릭 / 목표 달성 배지
- 집중 사운드(백색소음·빗소리 등) 재생 — 백그라운드 오디오 사용의 정당한 기능 제공
- 연속 착용 50분마다 목 스트레칭 리마인더

### 6.3 v2 (P2)
- 거북목(pitch) 감지
- 헤드 트래킹 기반 **목 스트레칭 가이드**(목표 각도까지 고개를 기울이면 체크되는 미니 게임)
- 홈 화면 위젯 / Live Activity(잠금화면에 현재 세션 상태)
- Apple Watch 진동 알림
- 프리미엄 구독(상세 리포트, 커스텀 사운드)

## 7. 화면 구성 (IA)

```
온보딩 (최초 1회)
 ├─ 1. 소개 (에어팟으로 목 자세를 지켜요)
 ├─ 2. 지원 기기 안내
 ├─ 3. 모션 권한 요청
 └─ 4. 알림 권한 요청 → 캘리브레이션

메인 탭
 ├─ 홈
 │   ├─ 연결 상태 배지 (AirPods Pro 연결됨 / 미연결)
 │   ├─ 머리 일러스트 + 현재 각도
 │   ├─ 오늘 요약 (바른 자세 %, 경고 n회)
 │   └─ [세션 시작] / [세션 종료] 버튼
 ├─ 기록
 │   ├─ 세션 리스트
 │   └─ 세션 상세 리포트 (타임라인 그래프)
 └─ 설정
     ├─ 다시 캘리브레이션
     ├─ 민감도 / 지속시간
     ├─ 알림 방식 (소리·진동·푸시)
     └─ 앱 정보 / 면책 고지
```

## 8. 알림 UX 원칙

- **조용하게, 하지만 확실하게**: 음악을 끊지 않고 위에 짧게 섞이는(mix) 알림음.
- **방향성 있는 소리**: 왼쪽으로 기울면 오른쪽 귀에서 소리 → 직관적으로 반대로 움직이게 유도.
- **스팸 방지**: 경고 후 쿨다운(기본 30초), 계속 무시하면 간격을 점점 늘림.
- **오탐 최소화**: 고개를 돌려 두리번거리거나 걷는 중 등 큰 움직임이 있을 때는 판정 보류.

## 9. 경쟁 / 참고

- 카메라 기반 자세 교정 앱: 폰을 세워둬야 해 일상 사용성이 낮음.
- 웨어러블 자세 교정기(등에 부착 등): 추가 구매 필요.
- AirPods 헤드 트래킹을 활용한 거북목 알림 앱이 일부 존재 →
  **좌우 기울기 특화 + 방향성 사운드 피드백 + 좌우 편향 리포트**로 차별화.

## 10. 법적 / 정책 고려

- 의료기기로 오인되지 않도록 "건강한 습관 형성 보조" 수준으로 표현, 면책 고지.
- 모션 데이터는 **기기 내에만 저장**(서버 전송 없음) — 개인정보 처리 부담 최소화, App Store 개인정보 라벨 단순화.
- `NSMotionUsageDescription` 문구 필수.
- 백그라운드 오디오 모드 사용 시 App Store 심사 가이드라인(2.5.4) 준수 필요 — 실제 오디오 기능 제공으로 대응.
