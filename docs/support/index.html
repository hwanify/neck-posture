Plumb 지원

질문이나 문제는 여기에 남겨 주세요.

필요한 기기

헤드 트래킹을 지원하는 에어팟(AirPods Pro, AirPods Max, AirPods 3세대 이상)이 필요합니다.

각도가 이상하게 나와요

설정 → 기준 자세 → 다시 등록을 눌러 기준 자세를 새로 등록해 주세요. 왼쪽·오른쪽이 반대로 나오면 "좌우 바꾸기"를 누르세요.

화면을 끄면 알림이 오지 않아요

설정 → 측정 → 백그라운드 측정이 켜져 있는지, iPhone 설정에서 Plumb의 알림이 허용되어 있는지 확인해 주세요.

Plumb Support

For questions or problems, please open an issue here.

Requirements

AirPods with head tracking (AirPods Pro, AirPods Max, AirPods 3rd generation or later).

The angle looks wrong

Go to Settings → Posture → Set up again. If left and right are reversed, tap "Swap left and right".

No alerts with the screen off

Check that Settings → Measurement → Measure in background is on, and that notifications are allowed for Plumb in iOS Settings.
